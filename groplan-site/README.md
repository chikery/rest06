# GroPlan — AI 사업계획서 로드맵 코치

아이디어만 가진 예비 창업자가 **7단계 로드맵**을 따라 사업계획서를 완성하고,
각 단계에 맞는 **정부지원사업**을 자동으로 매칭받는 서비스의 랜딩 페이지 + 작성 도구 프로토타입입니다.

## 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 랜딩 페이지 (히어로 · 문제 제기 · 7단계 작동 방식 · 지원사업 매칭 · 작성 화면 미리보기) |
| `write.html` | 실제 작동하는 AI 작성 도구 프로토타입 (7단계 입력 → AI 초안 → 피치덱 완성) |

두 페이지는 서로 링크로 연결되어 있습니다 (`index.html` ↔ `write.html`).

## 실행 방법

별도의 빌드나 설치가 필요 없는 **순수 정적 HTML**입니다.

- 로컬: `index.html`을 브라우저로 바로 열면 됩니다.
- 또는 간단한 정적 서버:
  ```bash
  npx serve .
  # 또는
  python3 -m http.server
  ```

### GitHub Pages 배포

1. 이 리포지토리를 GitHub에 푸시합니다.
2. **Settings → Pages → Branch: `main` / root** 로 설정합니다.
3. 잠시 후 `https://<사용자명>.github.io/<리포지토리명>/` 에서 공개됩니다.

## 기술 메모

- 빌드 도구·프레임워크·의존성 없음 — HTML + 인라인 스타일 + 바닐라 JS.
- 폰트: Pretendard(국문), Bricolage Grotesque(영문 헤드라인) — CDN 로드.
- 작성 도구의 AI 초안 생성은 **데모용 목업**입니다. 실제 LLM·RAG 연동 전 단계의 흐름 프로토타입입니다.
